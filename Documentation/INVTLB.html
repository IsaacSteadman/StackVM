INVTLB (TLB Maintenance / Shootdown Group)

INVTLB is opcode 0x0F. The byte immediately following the opcode selects the sub-operation. INVTLB instructions are privileged and may only be executed at kernel privilege level (priv_lvl = 0); executing INVTLB at user privilege triggers a PROTECT_FAULT.

The full model (the no-ASID design, the TLPTR self-filter, SYNC vs. ASYNC completion, broadcast vs. remote-interrupt delivery, and the memory-ordering contract) is described in TlbShootdown.html. This page documents the encoding.

Note: This opcode replaces the old INT (0x0F) opcode; software interrupts are issued via CALL_E with the IS_INT flag. The earlier transactional INVTLB_BEGIN / INVTLB_COMMIT sub-operations have been removed in favour of the sub-operations below.

Sub-Operations

Sub-Op Name Encoding Stack Effect (pop order) Description
0x00 INVTLB_LOCAL [0x0F][0x00] [UInt64 tlptr, UInt64 vaddr_base, UInt64 page_count] -> [] Invalidate, in this core's TLB only, page_count pages starting at vaddr_base under address space tlptr.
0x01 INVTLB_ALL_LOCAL [0x0F][0x01] [] -> [] Flush this core's entire TLB (e.g. AP bring-up).
0x02 INVTLB_SINGLE [0x0F][0x02][flags] [UInt64 tlptr, UInt64 vaddr_base, UInt64 page_count (, UInt64 done_core if ASYNC)] -> [] Issue a shootdown for one (tlptr, vaddr_base, page_count) descriptor. flags select the semantics (see below).
0x03 INVTLB_MULTI [0x0F][0x03][flags] [UInt64 entry_ptr, UInt64 num_entries (, UInt64 done_core if ASYNC)] -> [] Issue a fan-out shootdown. entry_ptr points at an array of num_entries 24-byte descriptors {UInt64 tlptr; UInt64 vaddr_base; UInt64 page_count;} in kernel address space (resolved via KERNEL_TLPTR when paging is enabled, else physical).
0x04 INVTLB_ACK [0x0F][0x04] [UInt64 handle] -> [] Remote-interrupt fallback only: a core that serviced an INT_TLB_SHOOTDOWN acknowledges completion to the issuer using the handle supplied in the interrupt.

Sub-op values 0x05 and above are reserved (e.g. for future VMID / stage-2 ops).

Flags byte (INVTLB_SINGLE / INVTLB_MULTI)

Bit Name Meaning
0x01 ASYNC Do not block. On completion, deliver INT_TLB_SHOOTDOWN_DONE to done_core (popped from the stack). When clear (SYNC), the instruction retires only once the shootdown is complete.
0x02 REMOTE_INT Fallback: interrupt the matching cores (INT_TLB_SHOOTDOWN) instead of invalidating their TLBs by hardware broadcast. When clear, the broadcast path is used and remote cores are not interrupted.
0x04 ALSO_LOCAL Also invalidate the issuing core's own TLB for the descriptor(s).
0x08 INCLUDE_INTERMEDIATE Also drop cached intermediate page-walk entries (required when a non-leaf PTE was changed); default is leaf-only.

Encoding

INVTLB_LOCAL, INVTLB_ALL_LOCAL and INVTLB_ACK are 2 bytes ([0x0F][sub_op]). INVTLB_SINGLE and INVTLB_MULTI are 3 bytes ([0x0F][sub_op][flags]). All operands are taken from the data stack; pages are counted in units of the current VM-mode page size, and vaddr_base is page-aligned (low bits ignored).

Privilege

All sub-operations require kernel privilege (priv_lvl = 0). Executing INVTLB at user privilege triggers a PROTECT_FAULT.
