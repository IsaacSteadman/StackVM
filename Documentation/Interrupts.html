TLPTR (single) / entry-array pointer (multi) Virtual address base (single) / num entries (multi) Page count (single) / 0 (multi)
0x1F TLB_SHOOTDOWN TLB-shootdown request via the remote-interrupt fallback path: another core asks this core to invalidate a range. The handler invalidates the range with INVTLB_LOCAL and acknowledges with INVTLB_ACK using the supplied handle. (The recommended broadcast path does not raise this interrupt.) Interrupt arguments

The argument columns above are delivered to the handler through four read-only, kernel-only system registers SVSR_INT_ARG0..SVSR_INT_ARG3 (0x0E..0x11), which the processor populates immediately before entering the handler. (Page-fault and protection-fault details continue to be reported via SVSR_PAGE_FAULT_ADDR as well.)
