INT128 / BITOP (Extended 128-bit & Bit-Operation Group)

INT128 is opcode 0x0E. The byte immediately following the opcode selects the sub-operation. All arithmetic sub-operations work on 128-bit (16-byte) values. POPCNT and BSWAP sub-operations work on smaller operands.

Note: This opcode replaces the old SYSRET (0x0E) opcode.

128-bit Arithmetic Sub-Operations

For arithmetic sub-ops the stack must contain two 16-byte (128-bit) operands. The top-of-stack is the right-hand operand (b) and the value below it is the left-hand operand (a). The result is a single 16-byte value pushed onto the stack.

Stack Diagram (binary ops)

  • UInt128/Int128 a
  • UInt128/Int128 b
->INT128(sub_op)->
  • UInt128/Int128 result

POPCNT Sub-Operations (Population Count)

Count the number of set (1) bits in an N-byte value. Pops N bytes, pushes a 1-byte count.

Sub-Op Code Name Input Size
0x13 POPCNT1 1 byte
0x14 POPCNT2 2 bytes
0x15 POPCNT4 4 bytes
0x16 POPCNT8 8 bytes

BSWAP Sub-Operations (Byte Swap)

Reverse the byte order of an N-byte value in place (endianness swap). Pops N bytes, pushes N bytes.

Sub-Op Code Name Size
0x17 BSWAP2 2 bytes (16-bit)
0x18 BSWAP4 4 bytes (32-bit)
0x19 BSWAP8 8 bytes (64-bit)

Encoding

An INT128 instruction is always 2 bytes: [0x0E][sub_op]. Sub-op values 0x1A and above are reserved.
