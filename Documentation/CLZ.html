CLZ (Count Leading Zeros)

CLZ is a group of 4 instructions (opcodes 0x18–0x1B) that count the number of leading (most-significant) zero bits in the top-of-stack value. The result is pushed as a single byte, replacing the input.

Note: These opcodes replace the deprecated LROT instructions.

Instruction Opcode Input Size Result Range
CLZ1 0x18 1 byte (8-bit) 0–8
CLZ2 0x19 2 bytes (16-bit) 0–16
CLZ4 0x1A 4 bytes (32-bit) 0–32
CLZ8 0x1B 8 bytes (64-bit) 0–64

Stack Diagram

  • UIntN value
->CLZN->
  • UInt8 count

Pops an N-byte unsigned integer from the stack and pushes back a single byte containing the count of consecutive zero bits starting from the most-significant bit. If the input is zero the result equals the full bit width (8, 16, 32, or 64 respectively).

Examples:

  • CLZ8(0x0000_0001_0000_0000) = 47
  • CLZ8(0x8000_0000_0000_0000) = 0
  • CLZ8(0) = 64
  • CLZ4(0x0000_0001) = 31
