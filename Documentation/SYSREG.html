StackVM's system registers are accessed through the LOAD and STOR instructions with variant SYS_REG

Implementations can specify their own Model Specific registers with ids >= 0x20

Privilege Level

Privilege Level indicates the level of privilege the current thread
has. There are 4 privilege levels, 3 of which are intended for main
use (the hypervisor privilege level is not intended for main use).
The 4 privilege levels are as follows

  • KERNEL - Kernel space privilege
       has access to the entire phyisical memory space
       has access to all FLAGS, I/O, interrupts
  • USER - User space privilege
       cannot write to most of flags (no priority, vm mode, or priv lvl changing)
       cannot access I/O or interrupts without Kernel
       all SYSCALLs from here call into Kernel

Priority

Priority is the value that determines whether an interrupt request
pre-empts the currently running thread. If the priority number
currently in FLAGS is greater than the priority number of the interrupt
request then the interrupt request initiates a "switch_to_interrupt".

SysReg ISR (Interrupt Service Routine table)

This is a pointer to a table of 4096 bytes = 256 (number of interrupt codes) x 16 (8 bytes FLAGS, 8 bytes function pointer) bytes. This pointer is treated as a virtual address and is translated to a physical address in the current execution context when an interrupt occurs. It is recommended (but not required) that this pointer is 4096 byte aligned for better access performance. The reason unaligned access can reduce performance is virtual address to physical address translation and cache line alignment

When interrupt code n is triggered the processor reads the ISR table entry and builds a 48-byte interrupt frame on the ISR privilege's stack: 

uint64_t isr_flags = ((uint64_t *)SYSREG_ISR)[2 * n];
uint64_t addr      = ((uint64_t *)SYSREG_ISR)[2 * n + 1];
uint8_t  isr_priv  = (isr_flags >> 8) & 1;

/* Save caller stack pointer; switch to ISR privilege stack */
SYSREG[SVSRB_SP + current_priv] = SP;
SP = SYSREG[SVSRB_SP + isr_priv];

/* Push v3 48-byte interrupt frame (bp = sp after) */
push(user_ip);      /* [bp+40] */
push(user_sp);      /* [bp+32] */
push(user_bp);      /* [bp+24] */
push(saved_flags);  /* [bp+16] */
push(error_code);   /* [bp+8]  */
push(int_num);      /* [bp+0]  <- TOS */
BP = SP;

/* Apply ISR entry flags: sets privilege, priority mask, virt_mem_mode */
SYSREG_FLAGS = isr_flags;
JMP addr;
The isr_flags field follows the same bit layout as SYSREG_FLAGS. Setting bit 8 (priv=0) causes the handler to run at kernel privilege. Setting the priority field (bits 7:0) masks out lower-priority interrupts during the handler. The entire "switch to interrupt" sequence is atomic.

Return from an interrupt handler is performed with RET_E (IS_SYS=1, IS_INT=1) (IRET), which unwinds the 48-byte frame and restores FLAGS, BP, SP, and IP.
