LOAD ("Load Data" Instruction)

LOAD is instruction 10 (0x0A) and instructs the processor to load data onto the stack.

The byte following the LOAD instruction indicates the size of the data, as well as the source location.

Memory Ordering Byte (Atomic Variants)

All atomic LOAD variants (0x0E–0x15) consume one additional byte immediately after the BCR byte. This byte specifies the memory ordering guarantee:

Value Name Description
0 RELAXED No ordering guarantee beyond atomicity.
1 ACQUIRE No subsequent load/store may be reordered before this operation.
2 RELEASE No prior load/store may be reordered after this operation.
3 SEQ_CST Full sequential consistency.

A Note on the RES Variant

With RES the most significant bit of Size has a different meaning. If it is set the processor will push the result data on the stack

RES will always push the least significant [Size] bytes of ResSize of the result last (on top of the stack after the instruction executes). these bytes will still be in little-endian order
