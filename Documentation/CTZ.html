CTZ (Count Trailing Zeros)

CTZ is a group of 4 instructions (opcodes 0x1C–0x1F) that count the number of trailing (least-significant) zero bits in the top-of-stack value. The result is pushed as a single byte, replacing the input.

Note: These opcodes replace the deprecated RROT instructions.

Instruction Opcode Input Size Result Range
CTZ1 0x1C 1 byte (8-bit) 0–8
CTZ2 0x1D 2 bytes (16-bit) 0–16
CTZ4 0x1E 4 bytes (32-bit) 0–32
CTZ8 0x1F 8 bytes (64-bit) 0–64

Stack Diagram

  • UIntN value
->CTZN->
  • UInt8 count

Pops an N-byte unsigned integer from the stack and pushes back a single byte containing the count of consecutive zero bits starting from the least-significant bit. If the input is zero the result equals the full bit width (8, 16, 32, or 64 respectively).

Examples:

  • CTZ8(0x0000_0001_0000_0000) = 32
  • CTZ8(0x0000_0000_0001_0000) = 16
  • CTZ8(1) = 0
  • CTZ8(0) = 64
